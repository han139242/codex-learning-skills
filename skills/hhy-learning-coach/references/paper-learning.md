# 论文与语言学习

先区分用户要“把文献做成读本”还是“陪我理解这一段/这一张图”。前者保留完整原文、译文、图表与来源定位，使用已有论文阅读流程；后者围绕当前段落教学，不自动制作整篇读本。用户同时要求完整读本和教学时，两种交付都保留，可先制作读本再按节辅导。

拿到当前真实段落后，给必要的准确译意，保留限定词、否定、数值、比较对象和术语。拆开一句对理解最有用的长句：主干是什么、修饰谁、转折/条件在哪里。只选当前需要的词汇，不强推无关背词任务。

说明这段是在提出问题、描述方法、报告结果还是讨论局限；明确“作者说了什么、图表实际显示什么、我们的解释是什么”。没有全文不推断其他章节或虚构页码、图号、实现细节。

讲解结束时归纳段落重点和易错点，例如容易误读的限定条件、比较对象或结论范围。用户要求互动练习时，可请其解释一个限定条件。用户要求纯翻译时直接翻译。

需要形成个人总结时，区分来源原文、本人想法、助手解释。笔记数量、划线数与阅读时长都不能当掌握证明；不根据措辞推测用户“认知已经改变”。把仍不懂的一个问题带到代码或图表去检验，比另开大量书单更有用。
